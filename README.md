# تسنيم & سعيد AI - الإصدار 4.3

## 📋 المميزات
✅ دعم كامل لـ GitHub Marketplace  
✅ بروكسي ذكي تلقائي الاختيار  
✅ وضع MEM المتقدم (ابدأ بـ 11)  
✅ قاعدة معرفة متكاملة  
✅ واجهة عربية احترافية  
✅ عمل على GitHub Pages  

## 🚀 التنصيب السريع
1. انسخ الملفات الثلاثة (`index.html`, `style.css`, `script.js`)
2. ارفعها على GitHub Pages
3. افتح التطبيق وأدخل مفتاح API
4. اضغط "اختبار الاتصال"
5. ابدأ المحادثة!

## 🔑 الحصول على المفاتيح
### GitHub Marketplace:
1. اذهب إلى [GitHub Tokens](https://github.com/settings/tokens)
2. أنشئ توكن جديد (classic)
3. أعطه صلاحيات `repo` و `read:packages`
4. انسخ التوكن (يبدأ بـ `ghp_`)
5. أدخله في التطبيق

### DeepSeek المدفوع:
1. سجّل في [DeepSeek Platform](https://platform.deepseek.com)
2. أنشئ مفتاح API جديد
3. انسخ المفتاح (يبدأ بـ `sk-`)
4. أدخله في التطبيق

## ⚡ استكشاف الأخطاء
- **خطأ "unknown_model"**: غيّر النموذج من القائمة المنسدلة
- **خطأ اتصال**: فعّل وضع البروكسي في الإعدادات
- **خطأ 401/403**: تحقق من صحة مفتاح API
- **مشكلة في GitHub Pages**: تأكد من تفعيل البروكسي
