🔹 GitHub Marketplace:

  1. اذهب إلى GitHub Tokens
  2. انقر على "Generate new token (classic)"
  3. أعط الصلاحيات: repo, read:packages
  4. انسخ التوكن الذي يبدأ بـ ghp_
  5. الصقه في حقل GitHub في الإعدادات

🔹 DeepSeek المدفوع:

  1. سجّل في DeepSeek Platform
  2. انقر على "Create API Key"
  3. انسخ المفتاح الذي يبدأ بـ sk-
  4. الصقه في حقل DeepSeek في الإعدادات

⚡ نصائح استكشاف الأخطاء:

  • إذا ظهر خطأ "unknown_model": غيّر النموذج من القائمة المنسدلة

  • للتأكد من عمل البروكسي: اضغط على "اختبار جميع البروكسيات"
